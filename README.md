# Pathfinding Visualizer

Visualizador interativo de algoritmos de busca em grade, desenvolvido com HTML, CSS e JavaScript puro.

## ✨ Demonstração

https://anaclrsnts.github.io/projeto_path_visualizer/

## Funcionalidades

- Grade interativa 20 × 12
- Criação e remoção de paredes
- Pontos inicial e final arrastáveis
- Breadth-First Search
- Dijkstra
- A*
- Animação da busca e do caminho
- Limpeza do caminho ou da grade
- Layout responsivo

## Como executar

Abra `index.html` no navegador ou publique o repositório no GitHub Pages.
